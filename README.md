# تطبيق الشيخ د. محمد الأمين إسماعيل — Kotlin

هذه نسخة Android أصلية مبنية بـ Kotlin، وتعيد بناء الهوية البصرية الأساسية للنسخة المرفقة: شاشة ترحيب متحركة، ألوان أخضر داكن وتركوازي، واجهة عربية من اليمين إلى اليسار، بطاقات الأقسام، قائمة المحاضرات، وزر تشغيل الصوت.

## مشغل ستارة الإشعارات

يستخدم المشروع **Jetpack Media3 ExoPlayer وMediaSessionService**. عند بدء تشغيل محاضرة من الواجهة، يستمر الصوت في الخلفية وتظهر جلسة الوسائط في ستارة الإشعارات، مع أزرار النظام للإيقاف والاستئناف والتقديم/الترجيع بحسب واجهة الجهاز. هذا هو الأسلوب الرسمي لتقديم تجربة وسائط موحدة عبر إصدارات Android الحديثة.[1]

لا يمكن لأي تطبيق أن يفرض ظهور إشعار أو يتجاوز إعدادات النظام وخصوصية المستخدم. في Android 13 وما بعده قد يطلب النظام إذن الإشعارات، كما أن شكل بطاقة المشغل وعدد الأزرار يختلف حسب الشركة المصنعة وإصدار Android. لذلك صُمم التطبيق باستخدام MediaSession وforegroundServiceType="mediaPlayback" بدل محاولة رسم إشعار مزيف.

## البناء

افتح مجلد المشروع في Android Studio حديث، ثم انتظر مزامنة Gradle وشغّل `app`. الحد الأدنى المضبوط هو Android 6.0 / API 23، وcompile/target SDK هو 35. يلزم اتصال إنترنت أول مرة لتنزيل مكتبات Gradle وMedia3، كما يلزم اتصال إنترنت لتشغيل الروابط البعيدة ما لم تُضف طبقة تنزيل محلي لاحقًا.

## الملفات المهمة

| الملف | الوظيفة |
| --- | --- |
| `MainActivity.kt` | الواجهة العربية، شاشة الترحيب، البطاقات، وبدء التشغيل |
| `PlaybackService.kt` | ExoPlayer وMediaSession واستمرار التشغيل في الخلفية |
| `AndroidManifest.xml` | الإنترنت، خدمة التشغيل، ونوع foreground service |
| `res/drawable/sheikh.jpg` | الصورة المرفقة المستخدمة داخل التطبيق |

## ملاحظة عن النسخة الحالية

تم نقل الوظائف الأساسية من HTML المرفق إلى نواة Kotlin قابلة للبناء، مع إبقاء روابط Archive.org التجريبية الظاهرة في الملف. لم يُضمَّن بعد مدير تنزيل كامل وقاعدة بيانات للمفضلة/التنزيلات؛ يمكن إضافتهما في المرحلة التالية باستخدام Room وDownloadManager/Media3 Cache. كذلك لا يمكن اختبار APK نهائي داخل هذه البيئة لعدم وجود Android SDK مثبت، لكن المشروع يحتوي على Gradle Wrapper وجاهز للفتح والبناء في Android Studio.
